# Ecom — Angular Client

**Angular 17** e-commerce client with server-side rendering, built to consume the [Ecom .NET 8 API](https://github.com/Ahmadjarad47/Ecom-App-.NET-8-With-Angular).

## Tech Stack

Angular 17 · TypeScript · RxJS · Angular SSR (Express)

## Getting Started

**Prerequisites:** Node.js 18+ and npm, and the Ecom API running.

```bash
git clone https://github.com/Ahmadjarad47/Ecom-Angular-With-DotNetApi.git
cd Ecom-Angular-With-DotNetApi
npm install
npm start        # http://localhost:4200
npm run build    # production build with SSR
```

Set the API base URL in the Angular environment configuration.
